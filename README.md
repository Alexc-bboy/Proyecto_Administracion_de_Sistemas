# Administración y Securización de Sistemas Linux Enterprise

## Descripción del proyecto

Este repositorio recoge el desarrollo de un laboratorio práctico de administración y securización de sistemas Linux Enterprise.

El objetivo es documentar los ejercicios realizados, las configuraciones aplicadas y los scripts desarrollados durante las prácticas.

## Entorno de laboratorio

- **Servidor:** Rocky Linux 8.10
- **Cliente:** Debian 13
- **Virtualización:** VirtualBox
- **Red interna:** LAB-LINUX

## Contenido

1. Instalación del servidor
2. Administración de usuarios
3. Cortafuegos
4. Auditoría y registros de seguridad en Linux
5. Automatización con Bash
6. Gestión de procesos y rendimiento
7. Administración de discos, sistemas de archivos y particiones
8. Redes y conectividad
9. Configuración SSH
10. Administración de servicios e infraestructura
11. Mantenimiento y administración empresarial
12. NFS y sistemas de archivos en red
13. Postfix
14. DNS con BIND
15. Apache
16. Docker

## Objetivos

- Aprender a administrar servidores Linux.
- Aplicar medidas de seguridad.
- Automatizar tareas mediante scripts Bash.
- Configurar servicios de red.
- Gestionar almacenamiento y usuarios.
- Desplegar y administrar servicios e infraestructura.
